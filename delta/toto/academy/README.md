# toto.academy

Learning management system (LMS) core for the delta maths e-learning host.
Courses, modules, lessons, enrollment, certificates, cohorts, the skill
forest UI, personalized learning paths, and hybrid badge recommendations.

## Purpose

A `Teacher` creates a `Course` structured into `CourseModule` → `Lesson`
chains. Each module unlocks a `competence.SkillBadge` and can carry an exam
`Quiz` plus attached practice quizzes; lessons carry a Vault video and PDF
notes. Students enroll (subscription-gated when an `academy*` plan is
active), practice, earn badges and certificates. `Cohort` groups students
under a teacher — surfaced in the classroom performance dashboards.
`PersonalPath` gives each student a self-service, gap-closing route to a
skill goal, and `recommendations.py` suggests the next goals.

## Models

- `Teacher` — a `Person` authorized to create courses (`person` OneToOne, `title`, `bio`, `is_active`).
- `Course` — `title`, `slug`, `description`, `author` (auth user), `owner` (Teacher), `is_published`, `is_virtual`, `order`.
- `CourseModule` — `course` FK, `unlocks_badge` (FK `competence.SkillBadge`, PROTECT), `verbena_page` (FK `palimpsest.Page`), `exam` (official `quizzes.Quiz`), `attached_quizzes` M2M, `lecture_video_url`, `order`.
- `Lesson` — `module` FK, `video_file` / `notes_file` (FK `vault.VaultFile`), `attached_quizzes` M2M, `order`.
- `Student` — `person` OneToOne; `badges` M2M through `StudentBadge(awarded_at)`; `enrolled_courses` through `CourseEnrollment(enrolled_at, completed_at)` — completion auto-creates a `Certificate`.
- `Certificate` — `uuid`, `person`, `course`, `exam`, `granted_at`, plus cryptographic signing fields (`signed_by` Teacher, `signing_key` → gervazy).
- `Cohort` / `CohortMembership` — a time-boxed class of students under a teacher; powers the classroom dashboards (`classroom-list` / `classroom-dashboard` views: completion funnel, practice progress, badge distribution, weekly activity charts).
- `LearningPath` / `LearningPathBadge` — a curated, admin-managed badge sequence (catalog; no student binding).
- `PersonalPath` / `PersonalPathStep` — a student's personalized route: goal badge XOR goal group, one active path per student (partial unique constraint), steps typed module / earn-badge / free-form task. Steps are generated by gap analysis + topological sort over the badge prerequisite DAG (`paths.py`) and re-synced against `StudentBadge` on every view.
- `RecommendationConfig` — singleton (pk=1) tuning for the recommender: `cf_strength` caps the collaborative share, `cold_start_students` controls shrinkage. Admin page includes matrix status and a manual recompute action.
- `Script` / `ScriptSection` — verbena `AbstractPage`/`AbstractSection` instructional pages attached to a module (trix rich-text sections).

## Services

- `paths.py` — `load_prerequisite_graph()`, `transitive_closure()`, `compute_gap_badges()` (Kahn topological sort with curriculum-order tie-breaks), `generate_steps()`, `sync_path()`, `regenerate_path()`.
- `recommendations.py` — hybrid goal ranking: content metrics (readiness, unlock power, tree continuation) blended with item-item cosine similarity over `StudentBadge`, read from a numpy matrix precomputed into the Django cache.
- `tasks.py` — `recompute_similarity_matrix` Celery task (daily beat + admin trigger).

## Dependencies

- `competence` — SkillBadge / SkillGroup and the prerequisite DAG
- `quizzes` — module exams and attached practice quizzes
- `palimpsest` — module notes/handout pages
- `vault` — lesson video/notes files
- `gervazy` — certificate signing keys
- `verbena` / `trix_editor` — Script pages and rich-text sections
- `people` — Person identity under Teacher/Student
